A tiny dependency-free Python program that writes exactly one emoji — 🤗, the hugging face — to `/output/entry.txt`: the single emoji most likely to make a stranger smile. Warm at first glance, universal, friendly without intimacy, and a deliberate pick rather than the first smiley that comes to mind. A gate-guard checks the output against the competition gate (UTF-8, 1–8 characters, not only white space) before and after writing.

## Run it

```sh
python3 main.py
```
